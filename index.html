Supabase · puesta en marcha

Se hace una sola vez y queda para todos los equipos

1Crear el proyecto

  1. Entra a supabase.com/dashboard → New project. Nombre: taller-apu. Región la más cercana. Guarda la contraseña de la base.
  2. Espera a que el proyecto termine de aprovisionarse (estado Healthy).

2Crear tablas, roles, seguridad y tiempo real

Ve a SQL Editor → New query, pega todo este script y pulsa Run. Crea las tablas, el alta automática de perfiles, las políticas RLS por rol y activa Realtime.

3Activar el acceso por correo

  1. Authentication → Providers → Email: habilitado. Para pruebas puedes desactivar Confirm email; en producción déjalo activo.
  2. Authentication → URL Configuration: en Site URL pon la dirección de tu página, por ejemplo https://apu-mantenimiento.github.io/TALLER-APU/.
  3. Crea tu cuenta desde esta misma página (pestaña Crear cuenta) y luego ejecuta el script del paso 4 para convertirte en administrador.

4Convertirte en administrador

Escribe tu correo y copia la sentencia en el SQL Editor. Sin este paso nadie puede aprobar usuarios ni cambiar la configuración.

5Conectar esta página y publicarla para todos

  1. Project Settings → API: copia Project URL y la clave anon public.
  2. Pégalas abajo. Pulsa Probar en este equipo para verificar el acceso.
  3. Pulsa Generar página conectada: descarga un index.html con la conexión ya escrita. Súbelo a la raíz del repo reemplazando el actual.
  4. Desde ese momento cualquier persona que abra la página inicia sesión y ve los mismos datos en vivo, sin sincronizar nada.

6Cargar la flota y verificar

Con la sesión iniciada y aprobada, esto crea una tarjeta por cada placa del CSV en Operativo en ruta. No sobrescribe las que ya existan.
