Apariencia para todo el equipo

Los trabajadores no pueden modificar la apariencia: ven exactamente lo que publiques aquí.

  1. Ajusta tema, saturación, texto, densidad, contraste, tramas e iconos en la barra superior.
  2. Pulsa Publicar para todos (descarga config_ui.json) o Copiar JSON.
  3. En GitHub: Add file → Create new file, nombre config_ui.json, pega el contenido y Commit (o sube el archivo descargado a la raíz del repo).
