Base de datos compartida

  1. Entra a console.firebase.google.com y crea un proyecto (gratis).
  2. Compilación → Realtime Database → Crear base de datos → modo bloqueado.
  3. En Reglas pega las reglas de abajo y publica.
  4. Configuración del proyecto → Tus apps → Web </> → copia el objeto firebaseConfig.
  5. Pégalo aquí abajo y pulsa Generar página conectada. Sube ese index.html al repo y listo: todos los equipos quedan en vivo, sin tokens ni sincronización manual.
