05 · Flujo de trabajo

1. Crear el repo

Sube el kit al repo TALLER-APU.

git init && git add . && git commit -m "init" git remote add origin https://github.com/APU-MANTENIMIENTO/TALLER-APU.git git push -u origin main

2. Activar Projects

GitHub → Projects → New project → Board. Crea las 6 columnas.

Columnas: · Backlog · Planificado · En desarrollo · En revisión · Listo para deploy · Completado

3. Cargar la flota

Edita data/flota/tractos.json y remolques.json.

data/flota/tractos.json data/flota/remolques.json data/catalogo/causas.json data/catalogo/estados.json

4. Registrar cambios

Crea un Issue con el template. El Kanban lo mueve según labels.

Labels: · estado:inoperativo · estado:operativo · estado:dor · estado:pm · prioridad:p1/p2/p3/p4
