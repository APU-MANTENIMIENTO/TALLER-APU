# TALLER FM

Sistema de seguimiento diario del estatus de taller para flota Volvo FM.

## Arquitectura
```
taller-fm/
├── app/          # Aplicación web
├── data/         # Datos de flota
├── docs/         # Documentación
└── .github/      # Workflows
```

## Instalación
1. Clona el repo
2. Abre app/index.html
3. Edita data/flota/*.json
4. Sube a GitHub Pages
